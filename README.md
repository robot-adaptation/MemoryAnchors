# MemoryAnchors — Minimal Flex-π Style Template

A minimal static site template matched to the visual system of [flex-pi.github.io](https://flex-pi.github.io): Source Serif 4 for body and headings, JetBrains Mono for metadata, a claret accent, a sticky top nav with an on-page outline rail, and a light "day" theme shipped by default with a full dark "night" theme one click away.

To preview locally, open `index.html` in your browser or serve with a simple HTTP server:

```bash
# from the project root
python3 -m http.server 8000
# then open http://localhost:8000
```

Files:
- `index.html`
- `css/style.css`
- `js/main.js` — theme toggle, scroll-spy for the outline rail, reveal-on-scroll
